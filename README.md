# Qwen-Image-2.1 на GTX 1080 Ti

## Установка в Windows

Текущее окружение `.venv` работает на Python 3.14.1, но содержит PyTorch
2.10.0+cpu без CUDA. Для приведённого ниже набора PyTorch 2.7.1 установите
Python 3.12 (64-bit) и Git, затем создайте отдельное окружение:

```powershell
py -3.12 -m venv .venv-pascal
.\.venv-pascal\Scripts\python.exe -m pip install --upgrade pip
.\.venv-pascal\Scripts\python.exe -m pip install -r requirements-pascal.txt
.\.venv-pascal\Scripts\python.exe -c "import torch; print(torch.__version__); print(torch.cuda.is_available()); print(torch.cuda.get_arch_list())"
.\.venv-pascal\Scripts\python.exe test.py
```

`requirements-pascal.txt` — отдельный набор зависимостей для этого запуска.
Не устанавливайте поверх него `requirements.txt`: там закреплены другие версии
PyTorch и torchvision. Пара PyTorch 2.7.1 / torchvision 0.22.1 с CUDA 12.6
взята из [официальной инструкции PyTorch](https://pytorch.org/get-started/previous-versions/#v271).
После установки проверьте реальный запуск CUDA на вашей карте.

## Генерация

Скрипт выбирает FP16 для GTX 1080 Ti, выгружает слои в оперативную память
через `enable_sequential_cpu_offload()` и декодирует VAE плитками.
Обычный `enable_model_cpu_offload()` переносит на GPU целые компоненты;
визуальный трансформер этой модели слишком велик для 11 ГБ в FP16.

Первый запуск скачивает веса модели и требует интернета, свободного места
на диске и значительного объёма RAM. Выгрузка слоёв экономит VRAM, но замедляет
генерацию; она не гарантирует, что модель поместится в оперативную память.
FP16 для этой модели необходимо проверить на практике: возможны проблемы
численной устойчивости.

Размер изображения — 512×512, число шагов — 40. Их можно изменить
в `test.py`. Результат сохраняется в папку `storage` рядом со скриптом
под уникальным именем; повторные запуски не перезаписывают предыдущие изображения.

## MemoryError при загрузке весов

CPU offload включается после `from_pretrained()` и не устраняет пик потребления
оперативной памяти при загрузке. Локальные веса всех компонентов занимают
около 32 ГиБ; преобразование BF16 в FP16 может временно потребовать дополнительную
память. На машине с 32 ГБ RAM и другими открытыми приложениями этого недостаточно.

Закройте приложения с большим потреблением RAM. В Windows откройте
`SystemPropertiesAdvanced.exe` → «Быстродействие / Параметры» → «Дополнительно» →
«Виртуальная память / Изменить». Для диска с достаточным свободным местом
можно задать начальный и максимальный размер файла подкачки 49152–65536 МБ.
Это отправная точка для повторной проверки, а не гарантия успешной генерации.
Примените настройки и перезагрузите компьютер, если Windows попросит.
Подкачка на SSD может сильно замедлить загрузку и генерацию.

Не отключайте mmap: чтение целого шарда в память увеличит пиковое потребление.
Если памяти всё равно не хватает, потребуется загрузка с выгрузкой на диск
или совместимый с Pascal вариант модели с квантованными весами.
